# Agent notes — Unsent: The Micro-Confession Sprint

Entry: a two-part micro-confession (a `To:` line + the unsent message, one
line, no explanation after it), written by `main.py` to `/output/entry.txt`.

Design choices, against the judge's brief:
- The addressee ("Dad") and the message need each other: the confession only
  makes sense to a father, and swapping the addressee breaks it.
- The reason it stayed unsent is felt in the words themselves: forgiveness
  was real years ago, but saying it out loud risks sounding like keeping
  score — so the message stays typed, never sent.
- Specific and honest, not a joke, greeting, or motivational line; it reads
  as something typed into a draft and abandoned, not written to be sent.
- Total length is well inside the 260-character limit; the message itself is
  well under 200 characters.
