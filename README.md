> To: Dad
> I forgave you years ago. I just never learned how to say it without sounding like I was still keeping score.

The entry is the confession itself: the reason it stayed unsent is inside the words — saying "I forgive you" out loud risks sounding like a ledger, so it stays typed and never sent.
